# Sindlish

**Programming in Sindhi. Building technology for Sindhi speakers.**

Sindlish is an open-source initiative focused on bringing Sindhi closer to the world of programming and technology.

The goal is simple: **language should not be a barrier to learning how computers work.**

Most programming languages are built around English keywords and terminology. While English is extremely useful in programming, it can also create an unnecessary barrier for people who are more comfortable thinking and learning in their native language.

Sindlish explores what programming could look like when **Sindhi is a first-class language in the programming experience.**

## What is Sindlish?

Sindlish is a high-level programming language designed for Sindhi-speaking communities.

It provides Sindhi-native programming keywords while retaining concepts familiar to modern programming languages. Sindlish is designed to be approachable for beginners while still being a real programming language capable of running programs through its own execution system.

Some of its current ideas include:

* 📝 **Sindhi-native syntax** — Write programs using Sindhi keywords.
* 🔄 **Hybrid typing system** — Variables can be either explicitly typed or have their types inferred automatically. Inferred variables can later change their type, while explicitly typed variables remain fixed to their declared type.
* ⚙️ **Bytecode virtual machine** — Programs can be compiled into bytecode and executed by a virtual machine.
* 🌱 **Beginner-friendly design** — The language is designed with education and accessibility in mind.
* 🛠️ **Open source** — The project is developed publicly and welcomes experimentation and contributions.

## Why Sindlish?

Programming is more than memorizing keywords.

It is about learning how to **think computationally, solve problems, and build things**.

We believe someone should be able to begin that journey in a language they understand deeply.

Sindlish is an experiment in making programming more accessible to Sindhi speakers—not by replacing English or existing programming languages, but by exploring what becomes possible when **Sindhi itself becomes part of the programming experience.**

## Our Vision

Sindlish is bigger than a programming language.

The long-term vision is to build an ecosystem around Sindhi and technology:

* Programming languages
* Developer tools
* Educational resources
* Documentation
* Libraries and frameworks
* Localization
* Experiments in Sindhi computing
* Tools that make technology more accessible to Sindhi speakers

This organization is where those projects can live and grow together.

## Projects

If you are interested in the future of **Sindhi + technology**, we'd love to have you involved.
